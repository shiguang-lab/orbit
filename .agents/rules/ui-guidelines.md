# Ant Design Component Sizing Rules

## Rule Definition
When developing or modifying pages in `apps/admin`:
1. **Buttons (`Button`)**: Always use standard default size. Do not pass `size="small"`.
2. **Segmented Controls (`Segmented`)**: Always use standard default size. Do not pass `size="small"`.
3. **Form & Input Controls (`Input`, `Select`, `InputNumber`, `DatePicker`, `Cascader`)**: Always use standard default size. Do not pass `size="small"`.
